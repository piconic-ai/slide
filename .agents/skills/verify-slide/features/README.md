# 機能の対応表

機能ごとに、入口、操作、動いたと言える結果を書く。仕様は [docs/features/](../../../../docs/features/) が正本で、ここには確かめ方だけを置く。機能を足したり入口を変えたりした PR は、同じ PR でこの表を直す。

`$O` は `http://localhost:8811` のように起動した origin を指す。

| 機能 | 入口 | 操作 | 動いたと言える結果 |
| --- | --- | --- | --- |
| [URL を渡して読んでもらう](../../../../docs/features/f03-sharing.md) | `$O/@kfly8/try-static`(匿名) | 開く | 200。`#deck` の iframe にスライドが出る。Chromium で console のエラーと失敗した request がない |
| 同上(ページの追従) | `$O/@kfly8/try-static/2` | 開く。スライドの中で矢印キーを押す | iframe の URL が `#2` で始まる。めくると、アドレスバーとコピー用の URL のページ番号が変わる(スライドがページを伝える場合) |
| [作者のみ限定公開で発表し、一般公開する](../../../../docs/features/f02-publication.md) | `$O/slides/try-static`(作者) | 「公開を停止する」を押す | D1 の `decks.paused_at` が入る。匿名で `$O/@kfly8/try-static` を開くと 404 |
| 同上(未ログイン) | `$O/slides`(匿名) | 開く | 401 とログインの画面 |
| [GitHub からスライドを更新する](../../../../docs/features/f01-github-deploy.md) | データを入れるコマンド(実際の uploader を通る) | 実行する | 2 つのスライドが ready になり、共有 URL が 200 になる。OIDC の実物は通らない |
| [知らない人のスライドも、安心して開ける](../../../../docs/features/f17-safe-viewing.md) | `$O/help`、`$O/@kfly8/try-static` | 開く。スライドの応答ヘッダーを見る | ヘルプに「できないこと」「できること」「気をつけること」の見出しがある。スライドの応答に `sandbox` と `frame-ancestors` の CSP が付く |
| 同上(運営による非表示) | `$O/slides/try-static`(作者)、`$O/@kfly8/try-static`(匿名) | 手元の D1 で `UPDATE decks SET hidden_at = 1, hidden_reason = '確認', hidden_by = 'local' WHERE id = 'try-static'` を実行してから開く | 作者の画面に「運営がこのスライドを非表示にしています。」と理由が出る。共有 URL は 404。運営の画面は、Cloudflare Access の token が要るので、ローカルでは開けない([運営による非表示の実装設計](../../../../docs/dev/f17-takedown.md#運営だけに開く)) |
| 同上(通報) | `$O/@kfly8/try-static`(匿名、作者) | 題名の右の「⋯」を開き、「通報する」を押す。匿名なら、ログインの案内が出る。作者でログインして、理由を選んで送る | 匿名は 401 と、戻り先がそのスライドのログインのリンク。ログイン後は「通報を受け付けました。」が出て、D1 の `reports` に 1 行入る。もう一度送っても 1 行のまま([通報の実装設計](../../../../docs/dev/f17-reports.md))。運営の画面の一覧は、Cloudflare Access の token が要るので、ローカルでは開けない |
| 同上(アカウントの停止) | `$O/slides`(作者) | D1 の `suspensions` に、作者の GitHub の user ID の行を入れてから、作者で開く。行を消して、もう一度開く | 行がある間は 403 と停止中のページ(理由、日時、問い合わせ先、退会、ログアウト)。`$O/@kfly8/try-static` と `$O/@kfly8` は 404。行を消すと、どちらも元に戻る([アカウントの停止の実装設計](../../../../docs/dev/f17-suspension.md))。運営の画面からの停止は、Cloudflare Access の token が要るので、ローカルでは行えない |
| 同上(ミュート) | `$O/@<ほかの作者>/<slug>`(作者) | 題名の右の「⋯」を開き、「この作者をミュート」を押して、次のページのボタンを押す。`$O/` と `$O/settings` を開く | 元のスライドに戻り、「⋯」に「ミュート中」と出る。トップページの最近の一覧から、その作者のスライドが消える。設定の「ミュートしている人」に出て、「解除」で戻る。ほかの作者のスライドが要るので、D1 に、もう 1 人の `accounts` と公開スライドを入れてから確かめる([ミュートの実装設計](../../../../docs/dev/f19-mute.md)) |
| 同上(問い合わせ先) | `$O/contact`(匿名) | 日本語と `?lang=en` で開く | 200。アドレス `contact@slide.community` が選択できる文字で出る。「準備中」の文言がない |
| [知りたい出来事が、お知らせに届く](../../../../docs/features/f20-notifications.md) | `$O/slides`、`$O/notifications`(作者) | 別の作者が、自分のスライドの共有 URL を含むスライドを一般公開する。管理画面から「お知らせ」を開き、引用のリンクをたどる。管理画面と一覧を開き直す | 未読の件数が 1 件増え、一覧に「新着」と引用元・引用先が出る。リンクから引用元を読める。開き直すと未読件数と「新着」が消える([お知らせの実装設計](../../../../docs/dev/f20-notifications.md)) |
| 同上(受信設定) | `$O/settings#notifications`(作者) | 「自分のスライドが引用された」を受け取らないように切り替え、別の作者に新しいスライドから引用してもらう。「受け取る」に戻し、さらに別のスライドから引用してもらう | 既定ではどの種類も「受け取る」。設定を変えても参加のお知らせの設定は同じまま。引用のお知らせは受信を再開した後の分だけ増える |
| [気になる人を、フォローする](../../../../docs/features/f21-follow.md) | 別の作者のスライドとプロフィール(ログイン済み) | スライドを 3 ページ目にめくり、作者名のそばの「フォロー」から確認して送信する。プロフィールの「フォロー中」から解除する | フォロー後は 3 ページ目に戻り、リンクが「フォロー中」になる。解除後はプロフィールに戻り、「フォロー」が出る。匿名の読者と作者本人にはどちらのリンクも出ない |
| 同上(設定とお知らせ) | `$O/settings#following`(読者)、`$O/notifications`(フォローされた作者) | 読者が作者をフォローし、作者がお知らせを開く。読者が設定の「フォローしている人」で「解除」を押す | 作者には読者のプロフィールへのリンク付きのお知らせが届く。読者は設定に戻り、一覧から作者が消える |
| 同上(ミュート中) | ミュート中の作者のプロフィール(読者) | 「フォロー」を開く | 確認ページにはミュートを解除する案内と設定へのリンクが出る。フォローの送信ボタンは出ない |
| 画面の言語 | `$O/slides/try-static`(作者) | `SLIDE_LOCALE=en-US` と `ja-JP` で開く | 題名と文言が、それぞれ英語と日本語になる |

## 注意

- データを入れ直すと、スライドの deployment が増える。件数を根拠にするときは、置き場を作り直す。
- Firefox は、管理画面で favicon の読み込みを CSP が止めたと console に出す(既知、#79)。この 1 件は失敗に数えない。
- Firefox と WebKit は、viewer で `postMessage` の送り先の origin が合わないと console に出す。Firefox は、デモのイベントが埋め込む外部の player の cookie についても出す。原因は調べていない。viewer の console を根拠にするときは Chromium で確かめ、ほかの engine ではこの 2 種類を除いて数える。
- `scripts/verify-upload.mjs` は既定の置き場(`.wrangler/state`)を使うので、`launch.sh` で起動した Worker には使えない。使い方は [アップロードの確認手順](../../../../docs/dev/f01-local-slice.md#ローカルで確認する) に従う。
