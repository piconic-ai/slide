# F15 登壇内容を読みながら動画と資料をたどる

状態は未実装の設計案です。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

配信を後から見る読者が、長い登壇動画の中から特定の説明だけを探している。文字起こしを読み、気になった段落から動画を再生し、その時に表示していたスライドへ移動する。

## 得られる結果

動画を最初から再生しなくても内容を探せ、話した説明と資料を行き来できる。将来の探索候補であり、初回リリースの要件にはしない。

## 体験の流れ

1. 作者が録音または字幕と、必要なら YouTube の参照 URL を用意する。
2. 手元か CI で文字起こし・記事化・ページとの対応表を作り、確認してアップロードする。
3. 読者が章や段落から該当時刻へ移動し、対応スライドを開く。

## 作る範囲

- 最初の実験は時刻付き字幕、ページ番号と時刻の対応表、編集済み Markdown 記事。
- 原文の文字起こしと編集した記事を区別し、元の発言へ戻れるようにする。
- 再生できない場合も文章と資料を読む体験を残す。

## 作らないこと

- サービス側の文字起こし・記事生成、生成クレジット。
- 任意の YouTube 動画をダウンロードして音声を抽出するサービス。
- 総合ポッドキャスト基盤と、許可前のタテブログへの実装。

## 受け入れ条件

- 段落から該当時刻へ移動し、対応がある箇所では正しい版のページを示す。
- 原文の引用と編集文を読者が区別できる。
- 有料・チーム限定の文字起こしがサンプルや検索データへ紛れない。
- 公開 YouTube 動画を参照する販売では、動画自体は公開のままであることと販売対象を示す。

## 未決事項

- 読者が動画・文字起こし・記事のどれを主に使うか、具体例で確認する。
- 字幕と対応表の形式、引用リンク、最初に対応するプレーヤー。
