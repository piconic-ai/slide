# F23 AI エージェントから置く

状態は実装中です。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

登壇者が、AI エージェントと会話しながら HTML スライドを作る。できあがったファイルは、エージェントの作業場所にある。それをダウンロードして、ブラウザで置き場に運ぶのは、会話の流れを切る。

## 得られる結果

できたところで「置いて」と頼むと、その会話のまま slide に置かれる。エージェントは 1 本の管理ページの URL を返し、登壇者はそこで確かめて公開する。

## 体験の流れ

1. 作者が、設定ページの MCP の URL をエージェントに登録する。初回だけ、ブラウザで接続を許可する。
2. スライドができたら、エージェントに「置いて」と頼む。
3. エージェントがファイルを渡し、1 本の管理ページの URL を受け取って作者に伝える。
4. 作者がそのページで表示を確かめ、「公開する」を押す。

## 作る範囲

- slide が `/mcp` で提供する MCP サーバー。接続の許可は OAuth で行う。
- 道具は 4 種類: 自分のスライドの一覧、新しく置く、新しい版に差し替える、状態を見る。
- 小さな HTML(文字のファイルの合計が 1MB まで)は、道具の引数で受け取る。それより大きいものと、画像などを含むものは、道具が送り先と一時の資格情報を返し、エージェントが HTTP で直接送る。
- 道具が返す、1 本の管理ページの URL と、作者だけが見られるプレビューの URL。
- 設定ページの、接続先の URL と、接続済みのエージェントの一覧・取り消し。

## 作らないこと

- 公開する、公開を止める、削除する、URL の名前を変える、設定を変える道具。一般公開は、人が押す操作として残す。
- 自分のコンピューターで動かす形(stdio)の MCP サーバー、コマンドの配布。
- スライドを作る・直す道具。slide は置き場で、作るのはエージェントである。
- 読者向けの道具(検索、閲覧)。

## 受け入れ条件

- **F23-AC1** 認可していないクライアントが `/mcp` を呼ぶと、認可が要ることを示す応答が返る。道具は呼べない。
- **F23-AC2** 作者がブラウザで接続を許可すると、そのクライアントから道具の一覧が取れる。
- **F23-AC3** 道具の一覧に、公開する、公開を止める、削除する道具がない。
- **F23-AC4** 「新しく置く」に小さな HTML を渡すと、スライドができ、1 本の管理ページの URL とプレビューの URL が返る。そのスライドは作者だけが見られる。
- **F23-AC5** 返ってきた 1 本の管理ページで「公開する」を押すと、共有 URL で見える。
- **F23-AC6** 引数で渡せる大きさを超える HTML は受け取らず、大きいもののための開始と確定を使うように伝える応答が返る。
- **F23-AC7** 開始が返した送り先に、エージェントがファイルを送って確定を呼ぶと、スライドができる。期限の切れた資格情報では送れない。
- **F23-AC8** 「差し替える」に、ほかの人のスライドを指定すると、断られる。存在するかどうかも伝わらない。
- **F23-AC9** 「差し替える」で新しい版を置いても、公開中の版は変わらない。
- **F23-AC10** 上限を超えるもの、接続を許可した後に登録から外された人の要求は断られ、理由が返る。
- **F23-AC11** 設定ページに、接続済みのエージェントが出る。取り消すと、そのエージェントの次の要求が認可エラーになる。
- **F23-AC12** 置いた HTML に、ページを伝える script が 1 つだけ入っている。

## 決めたこと

第一スコープを作るにあたり、次のように決めた(2026-11-19)。

- slide が MCP サーバーを `/mcp` で提供する。接続の許可は OAuth で行う。実装の前に、MCP の仕様と Cloudflare Workers の現行のドキュメントを読んで、やり方を決める。既存の認証(Better Auth、GitHub でのログイン)と組み合わせられないと分かったら、保留にする。
- 用意する道具は、自分のスライドの一覧、新しく置く、新しい版に差し替える、状態を見る、の 4 種類。公開する、公開を止める、削除する道具は作らない。
- 小さな HTML(文字のファイルの合計が 1MB まで)は、道具の引数で受け取る。それより大きいものと、画像などを含むものは、道具が送り先と一時の資格情報を返し、エージェントが HTTP で直接送る。受け取りは、[スライドを、ドロップして置く](f22-browser-drop.md) と同じ「開始、ファイルごとに送る、確定」の流れを使う。
- 道具は、1 本の管理ページの URL と、作者だけが見られるプレビューの URL を返す。
- 招待制と上限は、ブラウザから置くときと同じにする。
- 設定ページに、接続先の URL と、接続済みのエージェントの一覧・取り消しを置く。
- ページを伝える script の 1 行は、MCP の受け口が足す。
- トークンは、ハッシュで保存する。MCP の経路は cookie を読まない。
