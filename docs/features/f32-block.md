# F32 人をブロックする

状態は未実装の設計案です(第三スコープ)。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

作者が、しつこく絡んでくる人や、困った引用を繰り返す人に悩んでいる。ミュート([見たくない作者を、一覧から外す](f19-mute.md))は、相手のスライドを自分の一覧から外すだけで、相手は自分をフォローし続け、相手の引用はお知らせに届き続ける。通報するほどではないが、関わりを断ちたい。

## 得られる結果

困った相手をブロックすると、その人は自分をフォローできなくなり、その人のスライドと引用が、自分の画面とお知らせから消える。相手には知らされない。ブロックは、自分の設定からいつでも解除できる。

## 体験の流れ

1. viewer の「⋯」メニューの「この作者をブロック」、またはプロフィールの「⋯」メニューの「この人をブロック」を選ぶ。
2. 確認のページ(`/blocks/new?handle=…`)で、ブロックの効き目を読み、「ブロックする」を押す。
3. 互いのフォローが外れる。相手のスライドが、トップ、おすすめ、コミュニティとイベントの一覧、新着から消える。相手が自分のスライドを引用しても、お知らせや「引用された」に入らない。
4. 相手には、何も知らされない。相手が自分のプロフィールを開くと、「フォロー」が押せず、「この人はフォローできません。」とだけ出る。
5. 解除したくなったら、設定の「ブロックしている人」から「ブロックを解除」を押す。

## 作る範囲

- ブロックの表(ブロックした人、ブロックされた人、日時。2 人の組で一意)。
- 確認のページ `/blocks/new?handle=…` と、ブロックする・解除する経路(POST と CSRF の守り)。
- viewer とプロフィールの「⋯」メニューの入口。
- 効き目: フォロー、トップ、おすすめ、コミュニティとイベントの一覧、フォロー中の新着、引用の表示、お知らせ、「引用された」の数と一覧。除外の条件は 1 か所にまとめる。
- ブロックされた人から見たプロフィール。
- 設定の「ブロックしている人」の一覧と解除。

## 作らないこと

- 相手が書くリンク(引用)そのものを止めること。リンクは HTML の中にあり、止められない。自分の画面に出さないだけにする。
- 相手に自分のスライドを読ませないこと。公開中のスライドは、ログインしていない人と同じく、だれでも読める。
- コミュニティのフォローを止めること。「来るもの拒まず、去るもの追わず」にする。
- ブロックしたことを相手に知らせること。
- 通報の流れの変更。
- ミュートとの統合。ミュートはそのまま残し、別の一覧にする。

## 受け入れ条件

- **F32-AC1** A が B をブロックすると、A から B へのフォローと、B から A へのフォローが、どちらも外れる。
- **F32-AC2** B は A をフォローできない。B が見る A のプロフィールで「フォロー」は押せず(`disabled`)、下に「この人はフォローできません。」が出る。B からのフォローの送信は断られ、保存されない。
- **F32-AC3** A のトップ(最近のスライド、フォロー中の人の新着)と、viewer のおすすめ(引用の一覧)に、B のスライドが出ない。「ほか N 件」の数にも数えない。
- **F32-AC4** A が見るコミュニティのページとイベントのページの一覧と数、フォローしているコミュニティの新着に、B のスライドが出ない。
- **F32-AC5** B が A のスライドを引用しても、A にお知らせが届かない。
- **F32-AC6** B が A のスライドを引用しても、A が見る A のスライドの「このスライドを引用しているスライド」に出ない。
- **F32-AC7** B が A のスライドを引用しても、A のプロフィールの「引用された」の数と一覧に入らない。
- **F32-AC8** B は、ブロックされたことを知らされない。ブロックされたことを示す文言は、B のどの画面にも応答にも出ない。
- **F32-AC9** A が B のスライドの URL を直接開くと、ログインしていない人と同じく見られる。
- **F32-AC10** A は、設定の「ブロックしている人」から B のブロックを解除できる。解除すると、B のスライドと引用が A の画面に再び出る。フォローは戻らない。
- **F32-AC11** 自分自身はブロックできない。自分のスライドと自分のプロフィールの「⋯」メニューに、ブロックは出ない。自分を指すブロックの送信は断られる。
- **F32-AC12** ログインしていない人には、ブロックの入口が出ない。ログインしていない人の確認のページと、ブロックする・解除する送信は、ログインへ進むか断られる。
- **F32-AC13** ミュートの一覧とブロックの一覧は別である。設定の「ブロックしている人」は、「ミュートしている人」の上に出る。
- **F32-AC14** viewer の「⋯」メニューに「この作者をブロック」、プロフィールの「⋯」メニューに「この人をブロック」が出る。選ぶと確認のページへ進む。
- **F32-AC15** 確認のページは、見出し「(名前)さんをブロックしますか」、効き目の箇条書き、「ブロックする」と「やめる」、解除のしかたと通報の案内を持つ。本文の幅は 480px までで、幅 375px で横にはみ出さない。
- **F32-AC16** ブロックする・解除する送信は POST で、CSRF の守りを通らない要求(別の origin からの送信など)は断られ、状態が変わらない。
- **F32-AC17** ブロックしても、コミュニティのフォローは外れない。
- **F32-AC18** 退会すると、その人がしたブロックと、その人へのブロックが消える。
- **F32-AC19** ヘルプに、ブロックの項目がある(効き目、ミュートとの違い、解除のしかた)。日本語と英語の両方で読める。確認のページから、その項目へリンクしている。

## 決めたこと

第三スコープを作るにあたり、次のように決めた(2026-11-23、第三スコープの指示書)。

- ブロックの入口は、viewer の「⋯」メニューと、プロフィールの「⋯」メニュー。確認のページを経て、ブロックする。解除は設定の「ブロックしている人」から(D-70)。
- 効き目は次のとおり(D-71)。フォローは互いに外れ、ブロックされた人はブロックした人をフォローできない。相手のスライドは、ブロックした人のトップ、おすすめ、コミュニティとイベントの一覧、フォロー中の新着に出さない。相手が書いた引用は、書くことは止められないが、ブロックした人の画面に引用として出さず、お知らせも届けず、「引用された」の数と一覧にも入れない。コミュニティのフォローは止めない。相手の公開中のスライドは、直接開けば、ログインしていない人と同じく見られる。
- ブロックしたことは相手に知らせない。ブロックされた人のプロフィールでは、「フォロー」を押せなくし、「この人はフォローできません。」とだけ出す(D-72)。
- 第一スコープのミュートは、そのまま残す。ブロックとミュートは別の一覧にする(D-73)。
