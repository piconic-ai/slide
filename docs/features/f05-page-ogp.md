# F05 説明したいページを画像付きで共有する

状態は実装済みです(サービスが撮る分。作者がページの画像を用意する分は保留。本番の Browser Rendering での撮影は、人の確認が残る)。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

読者が資料の中の構成図を同僚に紹介する。資料の表紙だけではどの話か伝わらないため、そのページへのリンクを送り、チャット上のプレビューで内容を示す。

## 得られる結果

資料全体ではなく、伝えたいページを相手が開く前から識別できる。

## 体験の流れ

1. 読者がページ単位の共有リンク(`/@handle/slug/6`)を取得する。
2. サービスがそのページの画像を、必要になったときに撮って保存し、以後は同じ画像を返す。作者は何もしなくてよい。
3. 共有先がリンクのメタデータを取得し、ページ画像と見出しを表示する。

## 作る範囲

- HTTP のページ URL ごとのタイトル・説明・OGP 画像。
- 作者の画像がないときは、公開を許可されたページだけをオンデマンドで撮影する。全ページをアップロード時に一括生成しない。
- 同じ版・ページ・言語・描画設定の生成を重複させず、生成中・失敗時には用意済みの代替画像を返す。
- 有料スライドのページは作者が公開を認めた販売用情報だけでプレビューする。

## 作らないこと

- リンクが開かれるたびに作り直すこと。画像は HTML のスクリーンショットであり、生成 AI は使わない。
- 本文や画像が非公開のページを、OGP から見せること。

## 受け入れ条件

- **F05-AC1** fragment だけに依存せず、サーバーが共有対象のページを判定できる。
- **F05-AC2** 別の版や別言語の画像と混ざらない。
- **F05-AC3** 画像が欠けても資料を開け、購入前の URL から保護されたページ画像を取得できない。
- **F05-AC4** ページを伝える script を読み込んでいる公開中のスライドで、`/@handle/slug/6` の `og:image` が、6 ページ目を撮った画像の URL を指す。
- **F05-AC5** その画像の URL を開くと、JPEG が返る。
- **F05-AC6** `/@handle/slug`(番号なし)の `og:image` は、これまでと同じ表紙を指す。
- **F05-AC7** 版が `og:image` で自分の画像を指しているスライドでも、ページ番号つきの URL では、そのページを撮った画像を指す。
- **F05-AC8** ページを伝える script を読み込んでいない版では、ページ番号つきの URL でも表紙を指す。
- **F05-AC9** ページ番号が 200 を超える URL では、表紙を指す。撮影は行われない。
- **F05-AC10** あるページの撮影に失敗したとき、そのページの画像の URL は、表紙の画像を返す。表紙も返せないときは、表紙と同じ 503 と `Retry-After` を返す。
- **F05-AC11** 公開を止めた版、置き換えられた版のページの画像は、404 になる。
- **F05-AC12** 同じ版・同じページへの同時の要求で、撮影が 1 回にまとまる。
- **F05-AC13** ページの画像の経路が、表紙と同じ rate limit に入っている。

## SNS での表示方針

- X など SNS の大きいカード画像を基準に、初期案は 1200 × 630 px の PNG または JPEG。実際の投稿で切り抜き、文字の可読性、反映速度を確認して確定する。
- SNS が一度取得したカード画像をいつ更新するかは、その SNS が決める。作者が資料を直したり非公開にしても、過去の投稿に古い画像がしばらく残る場合があることを共有設定で説明する。

技術上の制約は [開発設計](../dev/design.md#access-control) を参照してください。

## 決めたこと

第一スコープを作るにあたり、次のように決めた(2026-11-19)。

- 画像は、必要になったときに撮る。アップロードの時点で全ページを撮らない。
- 対象は、ページを伝える script を読み込んでいる版だけにする。ページ番号は 1 から 200 まで。それ以外の番号、対象外の版、撮影の失敗では、表紙を使う。
- 総ページ数は取らない。ページ番号の綴りは `#6` の形だけに対応する。
- 作者がページの画像をアップロードする仕組みは作らない。それに関わる条件は、保留のままにする。
- 1 ページ目の URL(番号なし)は、これまでどおり表紙を使う。

## 未決事項

- 作者がページの画像を用意して、サービスの撮影より優先させる仕組み。保留。
- F05-AC2 のうち、言語ごとに画像を分けること。翻訳([別の言語で説明を読む](f06-localization.md))を作るときに決める。
- F05-AC3 のうち、購入前の URL から保護されたページの画像を取得できないこと。販売([スライドをコースにまとめて販売する](f12-paid-slides.md))を作るときに決める。
- 実際のブラウザが `#6` のページを描いて撮れることは、本番の Browser Rendering でしか確かめられない。

- 初回生成を待つ時間、生成失敗時の再試行間隔、SNS ごとの推奨比率。
- オンデマンド撮影の実行時間と回数を測り、初期の上限を調整する。
