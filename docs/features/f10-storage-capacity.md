# F10 容量を増やして資料を残す

状態は未実装の設計案です。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

図や音声を多く含む講義資料を継続して公開する作者が、無料枠の容量に近づく。過去の資料を削除せず新しい資料を追加したいため、使用量を見て PRO に変更する。

## 得られる結果

何が容量を使っているかを把握し、必要な保存量を選べる。

## 体験の流れ

1. 現在の使用量とプラン上限を確認する。
2. 資料・版・添付ファイルごとの容量を確認する。
3. 不要な公開候補を整理するか、大きい容量のプランへ変更する。

## 作る範囲

- PRO と TEAM の大容量枠、アップロード前の容量確認。
- 公開中のファイルだけでなく、保持する版・画像・音声を含む使用量の計上。
- 上限超過では既存ファイルを消さず、新規アップロードを止めて対処を案内する。

## 作らないこと

- 無制限の保存と、課金額や上限の未表示。
- 購入された版や差し戻し対象を、容量削減だけを理由に自動削除すること。

## 受け入れ条件

- 同時アップロードで容量枠を二重に使い越さない。
- 失敗・期限切れのアップロードが予約容量を永久に占有しない。
- ダウングレードで公開範囲が変わらず、対応が必要な超過を確認できる。

## 未決事項

- プラン別容量、ファイル単位の上限、保持する版数。
- 不要版を整理する画面と、削除前の猶予期間。

技術上の制約は [開発設計](../dev/design.md#operations) を参照してください。
