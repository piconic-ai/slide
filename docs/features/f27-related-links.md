# F27 関連リンクを紐付ける

状態は実装済みです(第二スコープ)。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

登壇者が、発表を終えたあとで、録画、ブログの報告、リポジトリを、スライドに添えたい。読者は、スライドを読んで、発表の録画や補足の記事も見たい。いまは、それらがスライドの外に散らばっていて、たどれない。

## 得られる結果

作者が、録画やブログ、その他のリンクをスライドに足すと、viewer の題名の下に並ぶ。読者は、スライドから録画や補足の記事へ進める。リンクは、無くてもスライドは共有できる。置く流れに、入力を挟まない。

## 体験の流れ

1. 作者が、スライドの編集の「関連リンク」の枠を開く。
2. 種類(動画、記事、その他)を選び、URL と題名を入れて「追加する」を押す。
3. 読者の viewer の、題名の下に、足した順で種類のアイコン、種類名、題名、サイト名が並ぶ。
4. 要らなくなったリンクは、「外す」を押して消す。

AI エージェントは、関連リンクを足す・外すことができる([AI エージェントから置く](f23-agent-upload.md))。

## 作る範囲

- 関連リンクの保存(スライドに属する。種類、URL、題名(任意)、足した順)。
- スライドの編集の「関連リンク」の枠。既存のリンクの行(種類のアイコン、種類名、題名、サイト名、「外す」)と、追加のフォーム(種類、URL、題名(任意)、「追加する」)。
- viewer の「関連リンク」の節。スライドの題名の下に、丸いリンクを横に並べ、折り返す。中身のないときは、見出しごと出さない。
- スライドの編集の、差し替えのドロップ枠の注記「記事と関連リンクも残ります。」。

## 作らないこと

- 動画の埋め込み。viewer の CSP を広げないため、リンクだけにする。
- リンク先の画像の取得、見せるときや後からの題名の取り直し。題名の自動取得は、題名を空にして足したときの 1 回だけ(F27-AC23 から)。
- リンクの並べ替え。足した順に並べる。
- 関連リンクを引用として数えること。共有 URL が入っていても数えない(引用はスライドと記事の中のリンクだけ)。
- 参加者がリンクを足すこと。参加者のレポートは、作者が「記事」として足す。
- イベントの紐付け、同じイベントの発表、イベントのページ。第三スコープでコミュニティと合わせて設計する。

## 受け入れ条件

- **F27-AC1** 作者は、スライドの編集の「関連リンク」で、種類(動画、記事、その他)、URL、題名(任意)を入れてリンクを足せる。
- **F27-AC2** 足したリンクは、viewer の題名の下に、足した順に出る。
- **F27-AC3** 題名のあるリンクは、種類のアイコン、種類名、題名、サイト名の 4 つで出る。サイト名は、URL のホスト名から出す。
- **F27-AC4** 「外す」を押すと、スライドの編集と viewer から、そのリンクが消える。
- **F27-AC5** `https:` 以外の URL(`http:`、`javascript:`、`data:` など)を入れたリンクは足せず、理由が出る。
- **F27-AC6** 削除。(題名は任意になった。題名の入力が空のリンクは足せる。F27-AC21 から。見える文字のない題名を断ることは F27-AC22)
- **F27-AC7** 100 文字を超える題名のリンクは足せず、理由が出る。ちょうど 100 文字なら足せる。
- **F27-AC8** 1 本のスライドに 11 件目を足そうとすると断られ、理由が出る。10 件までは足せる。
- **F27-AC9** スライドが一般公開中のとき、ログインしていない人の viewer にも、関連リンクが出る。
- **F27-AC10** スライドが作者のみ限定公開の間、作者は viewer で関連リンクを確かめられ、作者以外の viewer には出ない。
- **F27-AC11** 関連リンクが 1 件もないとき、viewer に「関連リンク」の節が見出しごと出ない。
- **F27-AC12** 関連リンクに、`rel="noopener nofollow ugc"` が付いている。
- **F27-AC13** ほかの人のスライドに、リンクを足す、外すことはできない。存在するかどうかも伝わらない。
- **F27-AC14** スライドの版を差し替えても、リンクは残る。
- **F27-AC15** スライドの編集の差し替えのドロップ枠に、「記事と関連リンクも残ります。」と出る。
- **F27-AC16** リンクの URL に共有 URL が入っていても、引用として数えない。
- **F27-AC17** 削除。(題名の自動取得を足したため、追加のときに題名が空なら 1 回だけリンク先へ問い合わせる。F27-AC23 から。見せるときの決まりは F27-AC29)
- **F27-AC18** スライドを削除すると、関連リンクも消える。
- **F27-AC19** 退会すると、その人のスライドの関連リンクも消える。
- **F27-AC20** 幅 375px の viewer で、関連リンクが折り返し、横にはみ出さない。
- **F27-AC21** 題名を空にしても、リンクを足せる。
- **F27-AC22** 題名を入れたときは、それを使い、リンク先へ問い合わせない。見える文字のない題名(ゼロ幅スペースだけ、空白に見える文字だけなど)、制御文字や向きを変える文字を含む題名は足せず、理由が出る。
- **F27-AC23** 題名を空にして足したときは、足すその 1 回だけ、サービスがリンク先のページから題名を取って保存する。`og:title` があればそれ、なければ `<title>`。文字の参照を解き、空白を 1 つにまとめ、前後を削り、100 文字に切る。
- **F27-AC24** 題名を取れなかったとき(応答しない、HTML でない、題名がない、題名が検査に通らないなど)も、リンクは足せる。題名なしで保存し、viewer と管理の画面には、サイト名(ホスト名)だけを出す。
- **F27-AC25** サービスは、次の先へ問い合わせない。IP アドレスのホスト、`localhost`、`.local`・`.internal`・`.localhost` で終わる名前、ドットのない名前、443 以外のポート、利用者名つきの URL、サービス自身と配信ドメイン。リンクは足せ、題名なしで保存する。
- **F27-AC26** リダイレクトは、サービスが手で、3 回まで追う。4 回目は追わない。行き先ごとに、F27-AC25 と同じ検査を通し、通らない先へは問い合わせない。
- **F27-AC27** 問い合わせは、全体で 3 秒まで。`text/html` の答えだけを読み、先頭の 64 KB で読むのをやめる。cookie と Authorization は送らず、User-Agent は `slide-link-title/1.0` にする。
- **F27-AC28** 取った題名は信用しない。F27-AC22 と同じ検査に通らないものは、題名なしにする。画面には、escape して出す(HTML としては出ない)。
- **F27-AC29** 保存したあと、viewer や管理を開くときに、サービスはリンク先へ問い合わせない。題名を取り直すこともしない。
- **F27-AC30** 追加のフォームの題名欄に、「空のままだと、リンク先の題名を自動で取ります。」(英語は同じ意味の文)と出る。
- **F27-AC31** AI エージェントの関連リンクを足す道具(`add_related_link`)は、`title` を省いてよい。省いたときは同じ取得をし、答えに、題名がどこから来たか(`given`、`fetched`、`none`)を含める。

## 決めたこと

第二スコープを作るにあたり、次のように決めた(2026-11-22)。

- 種類は「動画」「記事」「その他」の 3 つ。1 本のスライドに 10 件まで。
- 入れるのは種類、URL(`https:` だけ)、題名(100 文字まで、任意)。サイト名は URL のホスト名から出す。
- 2026-11-23、依頼者の判断で、題名の自動取得を作ると決めた(当初は「リンク先を取りに行かない」と決めていた。入力の手間をなくすことを、取得の守りを作る手間より優先した)。題名を空にして足したときだけ、足す 1 回、サービスがリンク先の題名を取る。取れなければ題名なしで保存し、サイト名だけを出す。足すことは失敗しない。取得の守り(内部の先へ行かない、リダイレクトの上限、時間、読む量)は[実装設計](../dev/f27-related-links.md#題名の自動取得)に書く。
- 並び順は足した順。並べ替えは作らない。
- viewer では、スライドが一般公開中のときに出す。作者は作者のみ限定公開の間も viewer で確かめられる。
- 関連リンクは引用として数えない。共有 URL が入っていても数えない(引用はスライドと記事の中のリンクだけ)。
- 動画は埋め込まない。viewer の CSP を変えない。
- viewer の並びは、スライド、題名と操作、説明、関連リンク、記事、引用の順([発表を書き起こした記事を添える](f26-article.md))。

## 未決事項

- 同じ URL を 2 件足そうとしたときに、断るか、許すか。実装は暫定で許している。作者が決める。
