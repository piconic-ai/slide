# F12 デッキをコースにまとめて販売する

状態は未実装の設計案です。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

連続講義や勉強会のシリーズを持つ登壇者が、複数のデッキを順番に並べ、各回のノートと動くデモを揃えた 1 つの教材として売りたい。読者は 1 回目を無料で読んで内容が合うか確かめ、続きを一度の支払いで手に入れたい。

## 得られる結果

作者はコースの価格と無料で読めるデッキを自分で決め、購入者へコース全体の閲覧権限を渡せる。読者は本を 1 冊買うのに近い納得感で、試してから買える。

## 体験の流れ

1. 作者が Stripe Connect の販売者登録を行う。
2. アップロード済みのデッキを順番に並べてコースを作り、価格・通貨と、無料で読めるデッキを選ぶ。無料にしないデッキは購入者だけが読める。
3. 未購入者としてコース紹介ページと無料デッキを確認し、販売を開始する。
4. 読者が無料デッキと販売条件を確認して購入し、残りのデッキを開く。

## 作る範囲

- コース単位の買い切り。無料デッキの任意選択。コース作成時は 1 回目を無料の初期値にし、あとから追加したデッキは有料扱い。無料デッキなしの販売。
- コース紹介ページに、各デッキのタイトルと順番、無料か購入が必要かを示す。
- 価格改定と、購入時点の価格・手数料・対象デッキの記録。
- Stripe Connect による販売手数料と、購入権限・返金・売上精算の管理。
- 有料デッキのファイルは購入者にだけ配信する。無料と有料の境界はデッキ単位にし、1 つの HTML の中でページを隠す方式は取らない。

## 作らないこと

- デッキ単体の販売、ページごとの個別購入、ページ単位の無料設定。デッキ単体へのお礼は [良かったデッキに投げ銭を送る](f16-tipping.md) で扱う。
- コピーを防ぐ DRM、生成クレジットの販売。
- 全ページ入りの HTML を送って一部のページだけ隠すこと。
- タテブログへの同時実装。はてな・KADOKAWA の許可後の将来候補とする。

## 受け入れ条件

- 無料デッキは連続していなくても選べる。デッキを新しい版に差し替えるときは、無料になる内容の実物を作者が確認してから反映する。
- 支払いの確定前に購入権限を渡さず、通知の重複で二重に付与しない。
- 未購入者が直接 URL を開いても、有料デッキの HTML・画像・説明文・音声・ノートを取得できない。
- 価格変更で既存購入の条件を変えず、無料デッキを減らした後に未購入者が古い URL から取得できない。
- 作者が販売・一般公開を停止しても、退会しても、既存購入者の閲覧は維持する。更新後は更新後の内容を読め、購入時点の版を選び直す機能は設けない。
- あとから追加したデッキは有料扱いにする。既存購入者には追加分も提供する。

## 未決事項

- 販売手数料率、通貨・価格の範囲、対応する販売者の地域。
- 返金条件と、運営による配信停止・サービス終了時の例外条件。
- 1 つのデッキを複数のコースに入れられるか。有料デッキの単独 URL を開いた未購入者に何を見せるか。
- 購入者の進捗(どの回まで読んだか)を保存するか、端末側だけにするか。

技術上の制約は [開発設計](../dev/design.md#billing) を参照してください。

公開停止後は [Zenn と同じ継続閲覧の方針](../dev/design.md#buyer-access-after-unpublish)を採用します。作者の都合による停止と、返金や運営による停止は分けて扱います。
