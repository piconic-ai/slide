# F12 無料ページで紹介して資料を販売する

状態は未実装の設計案です。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

講師が講義資料を販売する。購入前の読者には導入と構成図だけを見せ、内容が合うと判断した人に資料全体を一度の支払いで提供したい。

## 得られる結果

価格と無料ページを自分で決め、購入者へ完全版の閲覧権限を渡せる。

## 体験の流れ

1. 作者が Stripe Connect の販売者登録を行う。
2. 資料全体の販売価格・通貨と、無料公開する任意のページを設定する。
3. 未購入者として無料サンプルを確認し、販売を開始する。
4. 読者がサンプルと販売条件を確認して購入し、完全版を開く。

## 作る範囲

- 資料単位の買い切り、無料ページの任意選択、無料ページなしの販売。
- 価格改定と購入時点の価格・手数料・対象の版の記録。
- Stripe Connect による販売手数料と、購入権限・返金・売上精算の管理。
- 無料サンプルと完全版を分けてアップロードし、未購入者には完全版のファイルを送らない。

## 作らないこと

- ページごとの個別購入、コピーを防ぐ DRM、生成クレジット。
- 全ページ入りの HTML を送って有料ページだけ隠すこと。
- タテブログへの同時実装。はてな・KADOKAWA の許可後の将来候補とする。

## 受け入れ条件

- 無料ページは連続していなくてもページ番号で選べる。新しい版に差し替えるときは、無料になるページの実物を作者が確認してから反映する。
- 支払いの確定前に購入権限を渡さず、通知の重複で二重に付与しない。
- 未購入者が直接 URL を開いても完全版・保護画像・説明文・音声を取得できない。
- 価格変更で既存購入の条件を変えず、無料ページを減らした後に未購入者が古い URL から取得できない。
- 作者が販売・一般公開を停止しても、退会しても、既存購入者の閲覧は維持する。更新後は更新後の内容を読め、購入時点の版を選び直す機能は設けない。

## 未決事項

- 販売手数料率、通貨・価格の範囲、対応する販売者の地域。
- 返金条件と、運営による配信停止・サービス終了時の例外条件。
- 安全なサンプル出力に最初に対応する作成ツール。

技術上の制約は [開発設計](../dev/design.md#billing) を参照してください。

公開停止後は [Zenn と同じ継続閲覧の方針](../dev/design.md#buyer-access-after-unpublish)を採用します。作者の都合による停止と、返金や運営による停止は分けて扱います。
