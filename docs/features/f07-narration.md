# F07 ページの説明を音声で聴く

状態は保留です。トップページで約束する体験に含めないため、利用場面と優先順位を見直すまで着手しません。

## 利用場面

発表を見逃した読者が、資料の図を眺めながら作者の補足説明を聴く。作者は公開してよい説明文や録音をページごとに用意し、読者が必要なページだけ再生する。

## 得られる結果

スライドに書き切れなかった説明を、読む方法と聴く方法から選べる。

## 体験の流れ

1. 作者が公開用の説明文か、事前作成した音声ファイルを添付する。
2. 読者が再生を押す。
3. ページを移動したら再生を止め、次のページの説明を選べるようにする。

## 作る範囲

- 明示操作で始まるブラウザの読み上げと、アップロード済み音声の再生。
- ページ番号・言語別の音声。音声がない場合はテキストを残す。
- 作者が許可した公開用説明だけを対象にする。

## 作らないこと

- サービス側での音声生成と、生成クレジット。音声の生成は保留を解いても作者側で行う。
- 発表者ノートの自動読み上げと、閲覧開始時の自動再生。

## 受け入れ条件

- ページ移動で前の説明が流れ続けない。
- ブラウザで使える声が異なることと、再生できない場合があることを表示する。
- 有料・チーム限定の音声は、直接 URL でも権限なしに取得できない。

## 未決事項

- 音声ファイルの対応形式とサイズ制限。
- 再生速度・続きから再生を必要とする場面。

技術上の制約は [開発設計](../dev/design.md#access-control) を参照してください。
