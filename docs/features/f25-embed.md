# F25 ブログに埋め込む

状態は実装中です。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

登壇の後、登壇者がブログに報告の記事を書く。スライドへのリンクだけでは、読む人は記事を離れないと中身を見られない。記事の中で、そのままめくって読んでほしい。

## 得られる結果

登壇者は、viewer か 1 本の管理ページで埋め込みコードをコピーし、ブログに貼るだけで、記事の中でめくれるスライドを置ける。

## 体験の流れ

1. 作者または読者が、viewer の「共有」から「埋め込みコードをコピー」を押す。作者は、1 本の管理ページからもコピーできる。
2. コードをブログの記事に貼る。
3. 記事を開いた人が、記事の中でスライドをめくる。下端のリンクから、slide の viewer へ移れる。

## 作る範囲

- `/embed/@handle/slug`(ページ番号つきも可)。iframe に入れるための最小のページで、中身はスライドと、下端の題名・作者・slide へのリンクだけにする。
- 埋め込みコード。16:9 の `<iframe>` 1 つ。
- oEmbed の応答と、viewer の発見用の `<link>`。
- 1 本の管理ページの「埋め込みコード」の枠。

## 作らないこと

- はてなブログ、Zenn などへの個別の申請、専用記法への対応。
- 埋め込みの見た目を選ぶ設定(大きさ、開始のページ以外)。
- 作者が埋め込みを禁じる設定。
- 読まれた回数の計測。
- viewer 本体を、ほかのサイトに埋め込めるようにすること。viewer は、これまでどおり禁じる。
- 埋め込みの中での、cookie を使う操作(フォロー、通報、ミュート)。slide で開くリンクの先で行う。

## 受け入れ条件

- **F25-AC1** 「埋め込みコードをコピー」で入るコードを、別の origin の HTML に貼ると、スライドが表示され、めくれる。
- **F25-AC2** 同じ HTML に viewer 本体の URL を `<iframe>` で貼っても、表示されない。
- **F25-AC3** 一般公開されていないスライド、公開を止めたスライド、運営が非表示にしたスライドの `/embed/…` は 404 になる。
- **F25-AC4** 埋め込みの中のスライドは、埋め込み先のページを移動させたり、別タブを開いたり、フォームを送ったりできない。
- **F25-AC5** 埋め込みの中に、フォロー、通報、ミュートの操作が出ない。
- **F25-AC6** oEmbed の経路に、公開中のスライドの共有 URL を渡すと、`type`、`version`、`html`、`width`、`height`、`title`、`author_name` を持つ JSON が返る。それ以外の URL では 404 になる。
- **F25-AC7** 1 本の管理ページに、埋め込みコードとコピーのボタンが出る。一般公開する前は、公開すると使えることが 1 行で出る。
- **F25-AC8** 埋め込みコードは、`title` と `loading="lazy"` を持つ `<iframe>` 1 つで、幅に合わせて 16:9 を保つ。題名に引用符や `<` を含むスライドでも、コードが壊れない。
- **F25-AC9** viewer の `<head>` に、oEmbed の発見用の `<link>` がある。oEmbed の応答の `html` は、埋め込みコードと同じである。
- **F25-AC10** `/embed/@handle/slug/3` は、3 ページ目から開く。

## 決めたこと

第一スコープを作るにあたり、次のように決めた(2026-11-19)。

- 埋め込みは `/embed/@handle/slug`(ページ番号つきも可)に、iframe に入れるための最小のページを用意する。中身はスライドと、下端の題名・作者・slide へのリンクだけにする。このページだけ、ほかのサイトへの埋め込みを許す。viewer 本体は、これまでどおり禁じる。
- 埋め込めるのは、一般公開中のスライドだけ。公開を止めたら、埋め込みも見えなくなる。
- 埋め込みコードは、16:9 の `<iframe>` 1 つにする。あわせて oEmbed の応答を用意し、viewer に発見用の `<link>` を付ける。個別のブログサービスへの申請や専用記法への対応は範囲外にする。

## 未決事項

- 実際のブログサービス(はてなブログ、Zenn など)が、このコードと oEmbed を受け付けるか。ローカルでは確かめられない。
- 埋め込みを開いた読者について、埋め込み先と slide にそれぞれ何が伝わるかの、利用規約とプライバシーポリシーでの説明。
