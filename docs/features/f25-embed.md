# F25 ブログに埋め込む

状態は実装済みです(実際のブログサービスでの埋め込みは、人の確認が残る)。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

登壇の後、登壇者がブログに報告の記事を書く。スライドへのリンクだけでは、読む人は記事を離れないと中身を見られない。記事の中で、そのままめくって読んでほしい。

## 得られる結果

登壇者は、viewer の「共有」で埋め込みコードをコピーし、ブログに貼るだけで、記事の中でめくれるスライドを置ける。

## 体験の流れ

1. 作者または読者が、viewer の「共有」から「埋め込みコードをコピー」を押す。
2. コードをブログの記事に貼る。
3. 記事を開いた人が、記事の中でスライドをめくる。下端のリンクから、slide の viewer へ移れる。

## 作る範囲

- `/embed/@handle/slug`(ページ番号つきも可)。iframe に入れるための最小のページで、中身はスライドと、下端の題名・作者・slide へのリンクだけにする。
- 下端の行のない形(F25-AC12)。[トップを、1 本のタイムラインにする](f44-home-timeline.md) が、カードの中でスライドをめくるために使う。
- 埋め込みコード。`<iframe>` 1 つを、16:9 のスライドと下端の行の高さに保つ箱で包む。
- oEmbed の応答と、viewer の発見用の `<link>`。

## 作らないこと

- はてなブログ、Zenn などへの個別の申請、専用記法への対応。
- 埋め込みの見た目を選ぶ設定。大きさを選ぶ設定は作らない。下端の行のない形(F25-AC12)は、ブログ用の埋め込みコードにも、oEmbed にも出さない。開始のページは、URL のページ番号で指定する(F25-AC10)。コピーされるコードは、ページ番号なしである。
- 作者が埋め込みを禁じる設定。
- 読まれた回数の計測。タイムラインで開いたことを、閲覧とは別の記録として残すこと(F40-AC26)は、これに当たらない。
- viewer 本体を、ほかのサイトに埋め込めるようにすること。viewer は、これまでどおり禁じる。
- 埋め込みの中での、cookie を使う操作(フォロー、通報、ミュート)。slide で開くリンクの先で行う。

## 受け入れ条件

- **F25-AC1** 「埋め込みコードをコピー」で入るコードを、別の origin の HTML に貼ると、スライドが表示され、めくれる。
- **F25-AC2** 同じ HTML に viewer 本体の URL を `<iframe>` で貼っても、表示されない。
- **F25-AC3** 一般公開されていないスライド、公開を止めたスライド、運営が非表示にしたスライド、停止中の作者のスライドの `/embed/…` は 404 になる。
- **F25-AC4** 埋め込みの中のスライドは、埋め込み先のページを移動させたり、別タブを開いたり、フォームを送ったりできない。
- **F25-AC5** 埋め込みの中に、フォロー、通報、ミュートの操作が出ない。
- **F25-AC6** oEmbed の経路に、公開中のスライドの共有 URL を渡すと、`type`、`version`、`html`、`width`、`height`、`title`、`author_name` を持つ JSON が返る。公開中でないスライド(F25-AC3 と同じ)の URL と、共有 URL でない URL では 404 になる。
- **F25-AC7** 削除。(埋め込みコードは、viewer の「共有」からだけ取ることにした。スライドの編集の枠は外す。F25-AC11 で書き直した)
- **F25-AC8** 埋め込みコードは、`title` と `loading="lazy"` を持つ `<iframe>` 1 つと、それを包む箱である。置いた列の幅いっぱいに、スライドが 16:9 で横に黒い帯なく映り、その下に下端の行が欠けずに出る(16:9 は、枠全体ではなくスライドの部分の比である)。題名に引用符や `<` を含むスライドでも、コードが壊れない。
- **F25-AC9** viewer の `<head>` に、oEmbed の発見用の `<link>` がある。(`maxwidth`・`maxheight` を渡さないとき)oEmbed の応答の `html` は、埋め込みコードと同じである。
- **F25-AC10** `/embed/@handle/slug/3` は、3 ページ目から開く。番号の扱いは、共有 URL(F03-AC4)と同じである。
- **F25-AC11** スライドの編集に、埋め込みコードの枠がない。
- **F25-AC12** `/embed/@handle/slug`(ページ番号つきも可)に、クエリ `?t=compact` を付けて開くと、下端の題名・作者・slide へのリンクの行が出ず、スライドが枠の高さいっぱいに映る。`t` を付けない、または `compact` 以外のときは、これまでどおり、下端の行がある。

## 決めたこと

第一スコープを作るにあたり、次のように決めた(2026-11-19)。

- 埋め込みは `/embed/@handle/slug`(ページ番号つきも可)に、iframe に入れるための最小のページを用意する。中身はスライドと、下端の題名・作者・slide へのリンクだけにする。このページだけ、ほかのサイトへの埋め込みを許す。viewer 本体は、これまでどおり禁じる。
- 埋め込めるのは、一般公開中のスライドだけ。公開を止めたら、埋め込みも見えなくなる。
- 埋め込みコードは、`<iframe>` 1 つにする(2026-11-26 に、16:9 のスライドと下端の行の高さに保つ箱で包むことにした。下を見よ)。あわせて oEmbed の応答を用意し、viewer に発見用の `<link>` を付ける。個別のブログサービスへの申請や専用記法への対応は範囲外にする。
- oEmbed に `maxwidth`・`maxheight` を渡されたときは、応答の `width`・`height` と、`html` の `<iframe>` の `width`・`height` 属性を、16:9 のスライドと下端の行(45px)を合わせた大きさのまま、その上限に収まる同じ値にする。小数は切り捨てる。正の数でない上限には 400 を返す。上限を渡さないときの `html` は、コピーされる埋め込みコードと同じ文字列である(2026-11-20、レビューの指摘から)。下端の行を収める余地のない `maxheight`(45 以下)にも 400 を返す(2026-11-26)。

- 16:9 にするのは、枠全体ではなくスライドの部分である(2026-11-26、#529)。枠全体を 16:9 にすると、下端の行の 45px だけスライドの高さが足りず、スライドが横に縮んで左右に黒い帯が出た。CSS の `aspect-ratio` は比に固定の高さを足せないので、`<iframe>` を、幅に対する割合と 45px を足した `padding-top` を持つ箱で包み、`<iframe>` をその箱いっぱいに置く。貼る先のサイトに CSS を足してもらわずに済む。
- 埋め込みコードは、viewer の「共有」の「埋め込みコードをコピー」からだけ取る。スライドの編集には置かない(2026-11-20)。置き場が 2 つあると重なり、作者はどちらでも取れるので、viewer に 1 つにそろえた。一般公開されていないスライドでは、共有メニューに出さない(F03-AC17)。

2026-11-27 に、下端の行のない形を足すことにした(依頼者が 2026-11-26 に、[トップを、1 本のタイムラインにする](f44-home-timeline.md)で、カードの中のスライドに埋め込みのページを使うと決めた。相談のページ: https://claude.ai/artifact/Uq2hFKfqeRyAFFEDtPFYpx)。

- 形の切り替えは、既存の `/embed/@handle/slug`(ページ番号つき)の書き方に合わせ、クエリ `?t=compact` とする(2026-11-27、依頼者が決めた。当初の案は `?line=0` だった)。`t` は、type・template・theme のような「形」を指す名前で、`compact` が、下端の行のない形である。パスは変えない。クエリは、共有 URL の読み取り(パスだけを読む)に影響しない。ほかの名前の案は作らない。
- 下端の行のない形にも、F25-AC2(viewer の埋め込み禁止)、F25-AC3(公開されていない等は 404)、F25-AC4(埋め込み先を動かせない)、F25-AC5(フォロー、通報、ミュートが出ない)が、そのまま当てはまる。
- `t=compact` の形は、トップのタイムラインだけが使う。これを開いたことは、ブログからの閲覧と混ぜず、別の出どころ(`deck_opened` の `via` が `timeline`。`t=compact` のとき。それ以外は、これまでどおり `embed`)として記録する([運営が使われ方を知る](f40-operator-metrics.md) の F40-AC26)。これは、使われ方の記録を分けるもので、読まれた回数の計測ではない。下の「作らないこと」の「読まれた回数の計測」と食い違わない(閲覧として数えず、読者ごとの追跡もしない)。
- 埋め込みコード(F25-AC8)と oEmbed(F25-AC6、F25-AC9)は、下の行のある形のまま変えない。`html` は、クエリのない URL を指す。
