# F19 見たくない作者を、一覧から外す

状態は実装済みです。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

読者が、トップページや、スライドの下の一覧で、ある作者のスライドを何度も見かける。見たくないが、通報するほどの内容ではない。その作者のスライドを、自分の一覧から外したい。

## 得られる結果

読者は、見たくない作者を自分で外せる。外した作者のスライドは、すすめられない。URL を直接開けば、読める。外された作者には、知られない。

## 体験の流れ

1. 読者が、スライドを開く。
2. 題名の右の「⋯」メニューから、「この作者をミュート」を選ぶ。
3. トップページの最近の一覧、スライドの下の引用の一覧に、その作者のスライドが出なくなる。
4. その作者のスライドの URL を直接開くと、これまでどおり読める。
5. 同じメニューの「解除」を押すと、その作者のスライドが一覧に戻る。設定のページでも、ミュートしている人を確認して解除できる。

## 作る範囲

- viewer の「⋯」メニューの、ミュートと解除。ページを移らずに切り替わる。
- ミュートの保存(だれが、だれを)。
- すすめる一覧(トップページの最近の一覧、引用の一覧)から、ミュートした作者のスライドを外すこと。
- 設定のページの、ミュートしている人の一覧と解除。

## 作らないこと

- ミュートした相手に、自分のスライドを読ませないこと(ブロック)。ミュートは、自分の画面から外すだけにする。
- スライド単位、言葉単位のミュート。
- 期限つきのミュートと、ミュートの理由の入力。
- プロフィールのページからのミュート。入口は、当面、viewer の「⋯」メニューだけにする。
- ログインしていない読者のミュート(ブラウザに覚えさせる形)。

## 受け入れ条件

- **F19-AC1** ログインした人は、viewer の「⋯」メニューから、そのスライドの作者をミュートできる。
- **F19-AC2** ミュートした作者のスライドは、ミュートした人の画面で、トップページの最近の一覧、スライドの下の引用の一覧(引用している・引用されている)に出ない。「ほか N 件」の数にも数えない。
- **F19-AC3** ミュートした作者のスライドとプロフィールは、URL を直接開けば、ミュートした人にも読める。
- **F19-AC4** ミュートは、ミュートした人の画面にだけ効く。ほかの読者と、ログインしていない読者には、これまでどおり出る。
- **F19-AC5** 設定のページに、ミュートしている人の一覧が出て、解除できる。解除すると、その作者のスライドが一覧に戻る。
- **F19-AC6** ミュートされた人には、ミュートされたことが、どの画面にも応答にも出ない。
- **F19-AC7** 自分自身は、ミュートできない。自分のスライドの「⋯」メニューに、ミュートは出ない。
- **F19-AC8** 退会すると、その人がしたミュートと、その人へのミュートが消える。
- **F19-AC9** viewer の「⋯」メニューで、ミュートと解除が、ページを移らずに切り替わる。読んでいるページは変わらない。script が動かないときと、通信が失敗したときは、確認のページ、または設定のページで行える。
- **F19-AC10** ミュートしている作者のスライドとプロフィールには、フォローの操作が出ない。解除すると、フォローの操作が出る([気になる人を、フォローする](f21-follow.md))。

## 決めたこと

次のように決めた(2026-11-18)。

- ミュートは、いま作る。登録した人を対象にする。見たくないものを自分で外せることは、知らない人のスライドが並び始めた日から要るためである。
- ミュートした作者のスライドは、すすめる一覧のすべてから外す。すすめる場所があとで増えたときも、ミュートを効かせる。すすめる一覧を作る検索は、同じ条件を通す。
- URL を直接開いたときは、読める。プロフィールを直接開いたときも、その人のスライドの一覧を出す。
- 入口は、viewer の「⋯」メニューに置く。ふだん使わない操作を、目立たせないためである。
- viewer では、自身のスクリプトでミュートと解除を行い、読んでいるページと開いたメニューを保つ（2026-11-18）。作者が画面遷移を望まず、押し間違えてもその場で一度押せば解除できるためである。スクリプトが無効なときや操作に失敗したときは、ミュートは確認ページ、解除は設定のミュート一覧から行う。
- トップページの最近の一覧は、ログインしていない人には、これまでどおり、だれにでも同じ応答を返す(ブラウザが最長 60 秒使い回す)。ログインした人には、その人のミュートを反映した応答を返し、使い回させない。

## 未決事項

- なし。ミュートを、登録していない読者に開くかは、2026-11-27 に決めた。読者だけの登録は作らない。だれでも登録でき、登録した人が「ログインした人」である([知らない人のスライドも、安心して開ける](f17-safe-viewing.md))。
