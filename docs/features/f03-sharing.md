# F03 URL を渡して読んでもらう

状態は scope1 で実装済みです。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

勉強会の終了時、登壇者が参加者へ資料の URL を渡す。参加者はログインせずスマートフォンで開き、後日 PC で同じ資料を読み返す。

## 得られる結果

作成ツールをインストールしていない相手にも、ブラウザだけで資料を届けられる。

## 体験の流れ

1. 公開した資料の共有 URL をコピーする。
2. 相手が URL を開き、資料を閲覧・操作する。
3. 対応する資料では、説明したいページへのリンクを渡す。

## 作る範囲

- /@handle/slug 形式の資料 URL。
- 特定ページへの共有は、後続の [ページ単位の共有](f05-page-ogp.md)で対応する。
- 資料の独自 JS を隔離して動かし、相対パス・ルート相対パスのファイルを読み込む。外部への通信の制限は [知らない人のスライドも、安心して開ける](f17-safe-viewing.md) で扱う。
- ページ認識のアダプターがない HTML も、元の資料として表示する。

## 作らないこと

- SNS のフォロー関係、コメント欄、独自ドメイン。
- どんな HTML でもページを自動判定すること。

## 受け入れ条件

- 閲覧者がサービスのアカウントを持たず公開資料を開ける。
- ページ共有に対応した後は `/p/3` のようにページ番号でリンクする。作者がページごとの ID を設定する必要はない。資料の更新や並べ替えで3枚目の内容が変わったら、同じ URL が新しい3枚目を開いてよい。存在しない番号ではページが見つからないと表示する。
- 別の登壇者の資料とキャッシュが混ざらず、アップロードされた JS が管理画面の認証情報を読めない。

## 未決事項
