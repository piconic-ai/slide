# F06 別の言語で説明を読む

状態は未実装の設計案です。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

日本語で登壇した作者が、海外の同僚にも資料を渡す。作者が用意した英訳の説明文を添え、読者がスライドを見ながら自分の読める言語を選ぶ。

## 得られる結果

元の資料の見た目を維持しながら、説明文や見出しを別言語で読める。

## 体験の流れ

1. 作者が翻訳文と対応するページ番号 を手元または CI で準備する。
2. 言語別の成果物を資料と一緒にアップロードする。
3. 読者が言語を切り替えて説明文を読む。

## 作る範囲

- 資料の元言語・画面の言語・本文の言語を区別する。
- 作者が渡した本文、字幕、ページ見出しと説明の言語切り替え。
- 翻訳がないページは元の言語であると示す。

## 作らないこと

- サービスが翻訳モデルを呼び出すことと、生成クレジット。
- 任意の HTML 内の文字を置換し、レイアウトまで自動保証すること。

## 受け入れ条件

- 翻訳のない資料も元の資料として使える。
- ページと版を間違えて別の説明文を表示しない。
- 有料・チーム限定ページの翻訳は、本文と同じ閲覧権限で保護する。

## 未決事項
