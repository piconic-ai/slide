# F06 別の言語で説明を読む

状態は未実装の設計案です。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

日本語で登壇した作者が、海外の同僚にも資料を渡したい。翻訳を自分で用意する時間はない。読者はスライドを見ながら、説明を自分の読める言語で読みたい。

## 得られる結果

元の資料の見た目を維持しながら、記事とページの見出し・説明を別の言語で読める。

## 体験の流れ

1. 作者が、翻訳する言語を選ぶ。初期の対象は英語・中国語・韓国語。
2. サービスが、公開済みの記事とページの見出し・説明を AI で翻訳した下書きを作る。作者が自分で用意した翻訳があれば、そちらを使う。
3. 作者が翻訳を確認し、読者に見せることを選ぶ。
4. 読者が言語を切り替えて読む。

## 作る範囲

- 資料の元言語・画面の言語・本文の言語を区別する。
- [話した言葉といっしょに読む](f15-talk-reading.md) の記事と、ページの見出し・説明の翻訳。
- 作者による翻訳の確認・公開・取り下げと、作者が用意した翻訳の受け取り。
- 翻訳がないページは元の言語であると示す。
- 生成回数と文字数の上限。上限はプランと運用設定で決める。

## 作らないこと

- スライドの HTML 内の文字を置き換え、レイアウトまで自動で保証すること。
- 作者が確認していない翻訳を読者に見せること。
- 生成クレジットの販売。

## 受け入れ条件

- 翻訳のない資料も元の資料として使える。
- 元の記事を直したとき、古い翻訳を新しい内容の翻訳として表示しない。
- ページと版を間違えて別の説明文を表示しない。
- 有料・チーム限定ページの翻訳は、本文と同じ閲覧権限で保護する。

## 未決事項

- 作者が用意した翻訳の manifest 形式。
- 元の記事を直したときに、翻訳を自動で作り直すか、作者の操作を待つか。

技術上の制約は [開発設計](../dev/design.md#deployment) を参照してください。
