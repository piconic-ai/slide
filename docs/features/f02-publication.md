# F02 作者のみ限定公開で発表し、一般公開する

状態は実装済みです(手動の公開、停止、再開。リポジトリの設定に従う公開は、第一スコープで取り除いた)。2026-11-20 の見直しで、作者が viewer で確かめる形と、スライドの編集の整理を足した(F02-AC8 から)。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

発表前の登壇者が、まだ公開したくない資料を置く([スライドを、ドロップして置く](f22-browser-drop.md))。作者のみ限定公開で内容を確認し、そのまま会場の画面に映して発表する。発表終了後に一般公開して参加者へ URL を渡す。誤って公開したときは、すぐに公開停止する。

## 得られる結果

次の版を準備しながら公開中の資料を維持し、公開のタイミングを自分で決められる。

## 体験の流れ

1. 置いたスライドを、自分の viewer(`/@handle/slug`)で開く。公開する前は、スライドの上に「まだ公開していません。いまはあなただけが見ています。」と「公開する」が出る。表示とリンクを確認する。
2. 作者限定のまま会場の画面に映して発表する。
3. 発表後に、「公開する」で一般公開する。公開後は一般公開 URL を使い、作者限定の閲覧経路は閉じる。
4. 直した版を置いたら、スライドの編集で、「読者に見えている版」と「まだ公開していない新しい版」を見比べる。新しい版は viewer で見られる。「この版を公開する」で入れ替える。公開の停止も選べる。

## 作る範囲

- 作者のみ限定公開は、作者がログインしている間、一般公開前の確認と発表に利用できる。第三者への閲覧権限は渡さない。
- 作者限定の viewer。作者本人が自分の viewer を開くと、公開する前のスライドと、まだ公開していない新しい版が見える。読者には、これまでどおり 404 である。
- 作者限定での閲覧。発表者・観客の二画面操作は、保留中の [発表用と観客用の画面を分ける](f04-presenter.md) で扱う。
- 発表途中で短い固定期限により中断しないよう、認証と閲覧セッションを維持・更新する。
- 公開の方式は手動だけにする。公開、公開の停止、版の入れ替えは、作者が押したときだけ起きる。以前の版への差し戻しの操作は、第一スコープの画面から外した(下の「決めたこと」)。

## 作らないこと

- 公開予約と、URL を知る人だけが見られる第三者向け限定公開。
- リポジトリの設定に従う自動の公開。[GitHub からスライドを更新する](f01-github-deploy.md) と一緒にやめた。
- 版の履歴の一覧、受け取りの出どころ・状態・ファイルの数・deployment の ID を作者向けの画面に出すこと。作者が知りたいのは、読者に見えている版と、まだ公開していない新しい版だけである。
- 作者が自分のスライドを確かめるための、スライドの編集の中のプレビュー。確かめるのは viewer で行う。
- AI エージェントから公開すること([AI エージェントから置く](f23-agent-upload.md))。一般公開は、人が押す操作として残す。

## 受け入れ条件

- **F02-AC1** 公開中の版と次の作者限定の版が混ざらず共存する。
- **F02-AC2** 作者以外は限定公開の HTML・画像・音声を取得できない。
- **F02-AC3** 作者限定のまま発表を終えられ、一般公開後は限定公開用のセッションが無効になる。
- **F02-AC4** 削除。(CI からの受け取りと、リポジトリの設定に従う公開をやめた。F02-AC7 で書き直した)
- **F02-AC5** 公開停止後は、匿名の読者が古い HTML・画像・音声の直接 URL からも新規取得できない。購入済みの読者は継続して閲覧できる。取得済みの内容は取り消せない。
- **F02-AC6** 公開の枠に、方式の切り替えがない。公開の状態は、作者が押したときだけ変わる。
- **F02-AC7** 公開を止めた後に新しい版を受け取っても、再公開されない。公開を止める前に開始した受け取りが、止めた後に確定しても、再公開されない。
- **F02-AC8** スライドの編集に、deployment の ID、出どころ、受け取りの状態、ファイルの数、開始の日時が出ない。
- **F02-AC9** スライドの編集の公開の状態の文は、画面に 1 か所だけ出て、「公開中」「まだ公開していません」「公開を止めています」のどれかである。
- **F02-AC10** 公開中で新しい版がないとき、スライドの編集の版の行は「読者に見えている版」の 1 行だけである。
- **F02-AC11** 公開中のスライドに新しい版を置くと、スライドの編集に「まだ公開していない新しい版」の行が出る。
- **F02-AC12** 版の行に、受け取った日時と「見る」がある。新しい版の行には「この版を公開する」もある。
- **F02-AC13** 「この版を公開する」を押すと、同じ URL で読者に見える版が、新しい版に入れ替わる。
- **F02-AC14** 入れ替えた後、スライドの編集の版の行は「読者に見えている版」の 1 行に戻る。
- **F02-AC15** 削除。(公開の枠から、状態ごとの説明文と、止めるときの説明文を外した。F02-AC50 から。止めると読者が開けないこと、もう一度公開すると同じ URL で開けることは、ヘルプに書く。F02-AC51)
- **F02-AC16** スライドの編集に、以前の版へ差し戻す操作がない。
- **F02-AC17** 作者は、以前の版へ差し戻せる。(保留。理由は「未決事項」)
- **F02-AC18** 作者が、公開する前の自分のスライドの viewer(`/@handle/slug`)を開くと、スライドが枠に出て、めくれる。
- **F02-AC19** 公開する前のスライドの viewer は、ログインしていない人にも、ほかの作者にも、404 になる。
- **F02-AC20** 公開する前のスライドの viewer に、スライドの上に「まだ公開していません。いまはあなただけが見ています。」と「公開する」が出る。
- **F02-AC21** 公開する前のスライドの viewer に、「共有」が出ない。
- **F02-AC22** 帯の「公開する」を押すと、同じ URL を、ログインしていない人が開ける。
- **F02-AC23** 帯の「公開する」を押すと、帯が消え、「共有」が出る。
- **F02-AC24** 作者限定の版の中身を、別のスライドの中から script、fetch、iframe、画像として読み込んでも、中身が返らない。
- **F02-AC25** 作者限定の版を出すための値(token、署名)は、viewer の URL、ブラウザの履歴、Referer、サーバーのアクセスログに残らない。
- **F02-AC26** 公開を止めた後に、前に使った値で作者限定の版の中身を読めない。
- **F02-AC27** スライドを削除した後に、前に使った値で作者限定の版の中身を読めない。
- **F02-AC28** 作者が退会した後に、前に使った値で作者限定の版の中身を読めない。
- **F02-AC29** 公開中のスライドに新しい版があるとき、作者は、それを viewer で見られる。
- **F02-AC30** 公開中のスライドに新しい版があるとき、読者が viewer で見られるのは、公開中の版だけである。
- **F02-AC31** 新しい版を見るための値は、共有 URL に残らない。
- **F02-AC32** 削除。(理由: ボタンの名前を「ビューアで見る」に変えた。F02-AC52 で書き直した)
- **F02-AC33** 作者限定の版を出すための値の期限は、5 分以内である(設計の文書に書いた期限)。期限が過ぎた値では、中身が返らない。
- **F02-AC34** 作者限定の版を出すための値は、その版だけに効く。ほかの版の中身は、その値では返らない。
- **F02-AC35** 作者限定の版を出すための値は、その作者だけに効く。ほかのスライドの中身は、その値では返らない。
- **F02-AC36** 公開を止めているスライドを、作者が viewer で開くと、スライドが見える。
- **F02-AC37** 公開を止めているスライドの viewer に、スライドの上に「公開を止めています。いま読者には見えません。」と「もう一度公開する」が出る。
- **F02-AC38** 公開を止めているスライドの viewer は、ログインしていない人にも、ほかの作者にも、404 になる。
- **F02-AC39** 帯の「もう一度公開する」を押すと、同じ URL を、ログインしていない人が開ける。
- **F02-AC40** 読者に見えている版の行の「見る」を押すと、公開中の版の中身が viewer に出る。
- **F02-AC41** 新しい版の行の「見る」を押すと、新しい版の中身が viewer の枠に出る。
- **F02-AC42** 公開する前、または公開を止めている版の行の「見る」を押すと、その版の中身が viewer に出る。
- **F02-AC43** 版を指定しない viewer(`/@handle/slug`)を作者が開くと、公開中の版があれば公開中の版が出る。
- **F02-AC44** 公開中の版がないスライドの、版を指定しない viewer を作者が開くと、最新の受け取り済み(`ready`)の版が出る。
- **F02-AC45** 公開中のスライドの、まだ公開していない新しい版を作者が viewer で開くと、スライドの上に「いま見ているのは、まだ公開していない新しい版です。」と「この版を公開する」が出る。
- **F02-AC46** 帯の「この版を公開する」を押すと、読者が見る版が、その新しい版になる。
- **F02-AC47** 帯の「公開する」を続けて 2 回押しても、2 回目は失敗として出ず、公開された viewer に戻る。
- **F02-AC48** 作者の viewer の枠が開けないとき(ブラウザが cookie を保てない、確認の期限が切れた)、理由に合わせた文が出る。開けないブラウザには「公開すると、読者と同じように見られます。」と添える。別のタブで開く手段は、置かない。
- **F02-AC50** スライドの編集の公開の枠は、見出し「公開」と、その横の状態のタグ(「公開中」「まだ公開していません」「公開を止めています」)と、状態に必要なボタン 1 つだけを置く。読者が何をできるかの説明文は、枠に出ない。
- **F02-AC51** ヘルプに、公開を止めると読者はスライドを開けなくなること、もう一度公開すると同じ URL で開けることが、cookie と session の言葉を使わずに書いてある。
- **F02-AC49** 同じ秒に受け取った版は、置いた順に並ぶ。あとから置いた版が、必ず新しい側になる。公開した直後の同じ秒に新しい版を置いても、「まだ公開していない新しい版」の行が出る。(版の ID はランダムなので、並びの決め手にしない。#317)
- **F02-AC52** スライドの編集の「ビューアで見る」と版の行の「見る」は、viewer を開く。

## 決めたこと

第一スコープを作るにあたり、次のように決めた(2026-11-19)。

- スライド(deck)は、リポジトリの連携なしで作る。公開の方式は手動だけにし、リポジトリに従う方式(`repository`)はなくす。
- 置いた直後は、作者だけが見られる。公開中のスライドに新しい版を受け取ったときも、公開中の版は自動では入れ替えない。スライドの編集で、入れ替える操作を 1 回押す。

第一スコープの見直しで、次のように決めた(2026-11-20)。

- 公開の状態を出すのは、スライドの編集の公開の枠の 1 か所だけにする。文は「公開中」「まだ公開していません」「公開を止めています」の 3 つ。
- 版の履歴の一覧はやめる。出すのは「読者に見えている版」と「まだ公開していない新しい版」の 2 行まで。それぞれ、受け取った日時と「見る」を付ける。新しい版には「この版を公開する」を付ける。
- deployment の ID、出どころ、受け取りの状態、ファイルの数、開始の日時を、作者向けの画面に出さない。これらは GitHub の Actions で版を送っていたころに、実行と版を突き合わせるための情報で、ドロップと AI エージェントで置く今は、作者の判断に使われない。運営の画面では、これまでどおり出してよい。
- 「公開を止める」の説明は、作者が気にすること(止めると読者は開けない、もう一度公開すると同じ URL で開ける)だけを書く。cookie や session の言葉を使わない。
- 2026-11-23、依頼者の要望で、公開の枠を簡潔にした。状態のタグを見出しの横に置き、状態ごとの説明文と止めるときの説明文を外した。止めたときの注意は、ヘルプに移した(F02-AC15 から F02-AC50、AC51 へ)。
- 以前の版へ差し戻す操作は、第一スコープの画面から外す。仕組みと経路は残す。いま画面が出せる版は、読者に見えている版と、まだ公開していない新しい版の 2 つで、以前の版を選ぶ場面が、置く・確かめる・公開する・差し替えるの流れにない。使う場面が分かるまで、F02-AC17 を保留にする。
- 作者は、公開する前のスライドも、自分の viewer で見られる。読者には、これまでどおり 404 にする。公開する前のスライドの viewer では、スライドの上に「まだ公開していません。いまはあなただけが見ています。」と「公開する」を出し、「共有」は出さない。
- スライドの編集には、スライドのプレビューを置かない。題名の横に「ビューアで見る」を置き、版の行の「見る」も viewer を開く。
- 作者限定の中身を viewer の枠(iframe)に出す仕組みは、枠の中の launch と Partitioned cookie である([公開管理の実装設計](../dev/f02-publication.md#viewer-で見せる設計))。別のスライドの中から作者限定の中身を読めないこと(`src/preview/cross-deck.browser.test.ts` の守り)、値が履歴・Referer・ログ・共有 URL に残らないこと、期限が短いこと、公開を止めた後・削除した後・退会した後に使えないことを、満たす。
- 作者限定の中身を開く経路は、viewer の枠だけである(2026-11-20。依頼者の決定)。作者限定の配信 origin(`d-<ID>.<配信ドメイン>`)は内部の値で、作者に見せる機能ではない。別のタブで開く「作者限定で開く」は取り除いた。cookie を保てない古いブラウザでは、viewer の枠は開けず、理由を伝える文だけが出る。
- 公開を止めているスライドを作者が viewer で開くと、スライドが見え、上に「公開を止めています。いま読者には見えません。」と「もう一度公開する」が出る。読者には、これまでどおり 404 にする。「もう一度公開する」は、スライドの編集の「公開する」と同じ経路である。
- 版を指定しない viewer は、公開中の版があれば公開中の版を、なければ最新の `ready` の版を、作者にも出す。新しい版を見る方法(版を示す値)は、設計で決める。読者には効かず、共有 URL に残らないこと。版の行の「見る」は、その行の版を開く。
- 公開する前の版の行のラベルは「まだ公開していません」、公開を止めている版の行のラベルは「公開を止めています」にする(2026-11-20)。公開する前の行には「この版を公開する」を、公開を止めている行には「もう一度公開する」を付ける。公開の枠の状態の文と同じ言葉だが、行のラベルであり、状態の文ではない(F02-AC9 の数える対象は、公開の枠の状態の文)。
- 作者限定の版を出すための値は、viewer の URL、履歴、Referer、アクセスログに残さない。期限は 5 分以内で、その版と作者だけに効く(設計の文書に、期限の値を書く)。
