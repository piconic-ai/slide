# F11 どのページまで読まれたか確かめる

状態は未実装の設計案です。実装する段階は [ストーリーマップ](../story-mapping.canvas) で確認できます。

## 利用場面

勉強会の後、作者が説明を改善しようとしている。参加者に渡した資料が開かれたか、どのページまで読まれたかを集計で確認し、次回の内容を見直す。

## 得られる結果

資料の共有後の反応を、資料・版・ページ単位で振り返れる。

## 体験の流れ

1. PRO または TEAM のダッシュボードで対象資料と期間を選ぶ。
2. 閲覧開始とページ移動の集計を見る。
3. 修正前後の版を区別して、説明を改善する箇所を判断する。

## 作る範囲

- 信頼する viewer が送るイベントと、その期間別集計。
- 資料・版・ページに対応した閲覧分析。
- 保存期間と閲覧者のプライバシー設定の明示。

## 作らないこと

- キャッシュされたファイルのリクエスト数を、そのまま人間の閲覧数と表示すること。
- 広告向け個人追跡、読了や理解度を断定すること。

## 受け入れ条件

- 別の版のページ移動が同じ集計に紛れない。
- 分析の記録に失敗しても資料の閲覧を止めない。
- 未対応 HTML では把握できないページ移動を数えたことにしない。

## 未決事項

- 閲覧開始の重複排除、ボットの扱い、具体的な集計項目。
- 保存期間、閲覧者の選択肢、契約終了後の履歴の扱い。

技術上の制約は [開発設計](../dev/design.md#operations) を参照してください。
