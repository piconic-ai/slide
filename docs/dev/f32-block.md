# ブロックの実装設計

[人をブロックする](../features/f32-block.md) を実装するための契約。ここでは、ブロックの保存、除外の条件をどの問い合わせにどう足すか、ミュートとの違いを扱う。

## 保存

表 `blocks` に、「だれが、だれを」を 1 行で持つ(migration `0053_blocks.sql`)。

| 列 | 内容 |
| --- | --- |
| `blocker_user_id` | ブロックした人。利用者の id |
| `blocked_user_id` | ブロックされた人。利用者の id(`decks.owner_user_id` と同じ値) |
| `created_at` | ブロックした日時 |

主キーは 2 つの組である。同じ相手を 2 度ブロックしても、行は 1 つで、最初の日時を保つ。自分自身の行は、CHECK で拒否する。ブロックされた側から引く問い合わせ(フォローの可否)のために、`blocked_user_id` に索引を置く。

`block`(`src/blocks/store.ts`)は、同じ D1 バッチで、ブロックの行を足し、2 人の間のフォローを両向きとも消す。行を足すのは、2 人ともアカウントがあり、どちらも停止されていないときだけで、その条件を挿入の文に含める。フォローを消す文は、ブロックの行があるときだけ効く。すでにブロックしている相手を、もう一度ブロックしたときも、間に入ったフォローは消える。

解除(`unblock`)は、行を消すだけである。消えたフォローは戻さない。

退会すると、その人がしたブロックと、その人へのブロックを消す(`src/decks/deletion-store.ts` の `markAccountDeleted`)。

## 除外の条件

除外の条件は `src/blocks/store.ts` の 1 か所にまとめ、問い合わせごとに書き写さない。

| 関数 | 条件 | 使う所 |
| --- | --- | --- |
| `notBlocking(blocker, blocked)` | `blocker` が `blocked` をブロックしていない。引数は利用者の id か、それを持つ列 | ほかの関数の元。お知らせ、フォロー、プロフィールの「引用された」 |
| `notBlockedByOf(deck, viewer)` | 見ている人が、そのスライドの作者をブロックしていない。`deck` は `decks` の別名でもよい。`viewer` が `null`(ログインしていない)なら条件なし | スライドをすすめる一覧すべて |
| `notBlockedBy(viewer)` | `notBlockedByOf(decks, viewer)` | 同上 |

ミュートの `notMutedByOf` と同じ形にしてある。すすめる一覧には、両方を並べて付ける。

```ts
.where(and(notHidden, notMutedBy(viewer), notBlockedBy(viewer)))
```

件数は、表示する数に絞る前に条件を付けて数える。ブロックした作者のスライドは、「ほか N 件」にも数えない。

`src/share/takedown-readers.test.ts` が、`notMutedBy` を使う source のうち、`notBlockedBy` を使っていないものを見つけて失敗する。すすめる一覧を足すときは、両方を付ける。

### 効かせる所

| 所 | 条件 | 受け入れ条件 |
| --- | --- | --- |
| フォローの保存(`src/follows/store.ts` の `follow`) | `notBlocking(フォローされる人, フォローする人)`。ブロックされた人からのフォローは保存しない | F32-AC2、F21-AC64 |
| トップの「最近のスライド」「フォロー中の人の新着」(`src/share/store.ts` の `listPublicDecks`) | `notBlockedBy(viewer)` | F32-AC3 |
| スライドのページの、引用している・引用されている一覧と「ほか N 件」(`src/citations/store.ts`) | `notBlockedBy(viewer)` | F32-AC3、F32-AC6、F24-AC46 |
| プロフィールの「引用した」「引用された」の数と一覧、カードの引用の数(`src/citations/pair-store.ts`) | `notBlockedByOf(far, viewer)`。「引用された」には、さらに `notBlocking(プロフィールの人, 引用した作者)` | F32-AC7、F24-AC47 |
| お知らせの挿入と、一覧・未読の数(`src/notifications/store.ts`) | `notBlocking(受け手, 相手)` | F32-AC5、F20-AC13 |
| コミュニティとイベントの一覧と数、フォローしているコミュニティの新着 | `notBlockedByOf(deck, viewer)`。作業 C(コミュニティ)と F(コミュニティのフォロー)が、自分の問い合わせに付ける | F32-AC4 |

プロフィールの「引用された」は、プロフィールの人がブロックした人の引用を、だれが見ても数えない。D-71 が「ブロックした人のプロフィールの『引用された』の数と一覧にも入れない」と、見る人を限らずに決めているためである。ほかの一覧は、ミュートと同じく、見ている人のブロックだけを効かせる。

### 効かせない所

| 所 | 理由 |
| --- | --- |
| プロフィール(`/@handle`)の、その人のスライドの一覧 | 直接開いたので。ブロックした人も、ログインしていない人と同じく見られる(F32-AC9) |
| 共有 URL、配信、表紙 | 同上 |
| フォロー中・フォロワーの一覧 | 第三スコープの効き目(D-71)に入っていない |
| コミュニティのフォロー | 止めない(D-71、F32-AC17) |
| 作者の管理画面の「引用されたページ」(`readCitedPages`) | 自分のスライドがだれに引用されているかの記録で、すすめる一覧ではない |

## 入口と解除

| 経路 | 内容 |
| --- | --- |
| viewer の「⋯」メニュー | ログイン中の読者が別の作者のスライドを開くと「この作者をブロック」を出す。停止中の読者、ログインしていない人、作者本人には出さない |
| プロフィールの「⋯」メニュー | ログイン中の読者が別の人のプロフィールを開くと「この人をブロック」を出す。出さない人は viewer と同じ |
| `GET /blocks/new?handle=<handle>&slide=<戻り先>` | 確認のページ。ログインしていなければ、ログインの案内(戻り先つき)を 401 で返す。存在しない handle、形の違う handle、停止中の人、自分自身は 404 |
| `POST /blocks` | ブロックを保存し、303 で戻り先へ戻る。自分自身や、見えない handle は何も変えずに同じく戻る |
| `POST /blocks/:handle/release` | 自分がしたブロックを消し、303 で `/settings#blocks` へ戻る |
| 設定のページ(`/settings`) | 「ブロックしている人」の一覧と、「ブロックを解除」のボタン。「ミュートしている人」の上に置く |

戻り先は、共有 URL とプロフィールの path だけを受け付け(`returnToShare`)、それ以外は `/slides` にする。

どちらの POST もフォームの本文だけを受け付け、ほかの形式は 415 で返す。フォームの送信には CSRF の検査(`hono/csrf`。別の origin と、`Origin` の無い送信を断る)とログインが要る。停止中の人は、ログインしている人を引く所で拒否される。頻度の制限は、`management` の組に入る。

## ブロックされた人に知らせない

ブロックされた人(B)の画面と応答には、ブロックを示すものを出さない。

- B が見るブロックした人(A)のプロフィールでは、「フォロー」を `disabled` にし、下に「この人はフォローできません。」とだけ出す。
- B のフォローの送信は、保存されないだけで、フォームの応答はブロックの無いときと同じ形(303 で戻る)にする。
- B のトップ、お知らせ、設定、自分のプロフィールは、ブロックの前後で変わらない。A のフォローが外れた分だけ、フォロー中・フォロワーの数が変わる。

## ミュートとの違い

| こと | ミュート([実装設計](f19-mute.md)) | ブロック |
| --- | --- | --- |
| 表 | `mutes` | `blocks`。一覧も別 |
| フォロー | 自分から相手へのフォローだけ外す。相手は自分をフォローし続けられる | 両向きとも外す。相手は自分をフォローできない |
| 相手からのお知らせ | 届かない | 届かない |
| すすめる一覧 | 相手のスライドを外す | 相手のスライドを外す |
| プロフィールの「引用された」 | 見ている人のミュートで外す | 見ている人のブロックで外し、プロフィールの人のブロックでも外す |
| 入口 | viewer の「⋯」 | viewer とプロフィールの「⋯」 |
