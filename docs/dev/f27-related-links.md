# 関連リンクの実装設計

[関連リンクを紐付ける](../features/f27-related-links.md)の設計。作者がスライドに足した録画やブログのリンクを、viewer の題名の下に並べる。題名を空にして足したときだけ、足す 1 回、リンク先から題名を取る。リンクを引用として数えない。

## ファイルの分担

| ファイル | 層 | 役割 |
| --- | --- | --- |
| `src/links/link.ts` | 純粋 | 種類、上限、URL と題名の検査(`parseLinkInput`。URL は `src/share/https-url.ts` の `parseHttpsUrl` で、プロフィールのリンクと共有する)、サイト名(`siteNameOf`)、画面に戻すときの理由の解析 |
| `src/links/link-parts.ts` | 純粋 | 種類の名前(日本語と英語)と、種類のアイコン |
| `src/links/store.ts` | store | 一覧、追加、外す。上限と持ち主の確認は SQL に含める |
| `src/decks/links-frame.ts` | 純粋(HTML の部品) | 1 本の管理の「関連リンク」の枠 |
| `src/share/viewer-links-frame.ts` | 純粋(HTML の部品) | viewer の「関連リンク」の節 |
| `src/decks/routes.ts` | routes | `POST /slides/:deck/links`、`POST /slides/:deck/links/:link/delete` |

## 表

`related_links`(migration 0039)は、スライド(`deck_id`)に属する。版には属さないので、版を差し替えても残る(F27-AC14)。

| 列 | 内容 |
| --- | --- |
| `id` | リンクの鍵(UUID)。「外す」が指す |
| `deck_id` | スライド。`decks` を参照する |
| `kind` | `video`、`article`、`other`。CHECK で縛る |
| `url` | 正規化した `https:` の URL |
| `title` | 題名。入力か取得で入った 1〜100 文字(CHECK)。入らなかったときは NULL(migration 0045 で NOT NULL を外した)。画面は NULL のとき、サイト名だけを出す |
| `position` | 足すたびに最大値 + 1。外しても詰めず、再利用しない。並びは `position` の昇順 |
| `created_at` | 足した時刻 |

`(deck_id, position)` は一意。並べ替えは作らない(D-52)。

## 足す

`addLink` は、持ち主の確認、スライドの存在、10 件の上限を、1 つの `INSERT ... SELECT ... WHERE` に含める。事前に件数を数えて足すと、同時の追加が上限を超えうるためである(`src/links/links.test.ts` に同時の追加のテストがある)。0 行しか入らなかったときは、スライドが自分のもので生きているかを引き直して、`full`(上限)と `missing`(ほかの人のもの、無い、削除済み)を分ける。`missing` は、スライドが無いときと同じ 404 で答える(F27-AC13)。

「外す」も、リンクの鍵とスライドと持ち主を 1 つの `DELETE` の条件にする。

## URL と題名の検査

境界(routes)で `parseLinkInput` を 1 度だけ通し、store には解析済みの値を渡す。

- URL は、前後の空白を除いたうえで、空白と制御文字を含むものを断る。URL の解析は、途中の tab や改行を黙って取り除くので、解析の前に見る。
- 2,000 文字を超えるもの、`new URL` が解析できないもの、`https:` 以外(`http:`、`javascript:`、`data:`、`//host`、スキームの無いもの)、利用者名やパスワードを含むものを断る。保存するのは `URL.href` の正規の綴りである。
- 題名は任意。前後の空白を除いて空なら、取得に回す(`title: null`)。入力があるときは、1〜100 文字(コードポイントで数える。絵文字は 1 文字)。制御文字(改行、C1 を含む。`\p{Cc}`)、書式文字(ゼロ幅スペース、左右の向きの印と上書き。`\p{Cf}`)、行と段落の区切り(U+2028、U+2029)は断る(`title_invalid`)。そのうえで、見える文字が 1 つもない題名(空白、全角の空白、U+3164 や U+2800 のような空白に見える文字だけ)は、断る(`title_missing`。入力が空なのとは別で、空は断らない)。
- 断った理由は、`?links=<理由>` として管理のページへ戻して、枠の上に 1 文で出す(`role="alert"`)。入力した値は戻さない。

## サイト名

URL のホスト名を、`URL.hostname` のまま出す。国際化ドメイン名は、`xn--` で始まる ASCII の綴り(punycode)になる。

- **暫定の判断(作者の確認が要る)**: 仕様の未決事項「Unicode のまま出すか、ASCII の表記で出すか」は、ここでは ASCII で出す。理由は、見た目が似た別のドメインを本物に見せる偽装(ホモグラフ)を、読者に見えるサイト名で許さないためである。日本語のドメインは読みにくくなる。
- `www.` は取り除かない。

## 同じ URL

- **暫定の判断(作者の確認が要る)**: 同じ URL を 2 件足すことは、断らずに許す。仕様の未決事項が残っているため、検査を足していない。断るなら、`parseLinkInput` ではなく store の条件に足す。

## 見せる

viewer は、そのページを返す条件を満たす人に、リンクを出す。一般公開中のスライドは読者のだれにでも、作者のみのスライドは作者の preview だけに開くので、リンクの読み取りは版を選んだあとに、スライドの鍵で 1 回行う。ほかの人に開かない状態では、ページそのものが 404 になり、リンクは出ない(F27-AC9、AC10)。

節は、リンクが 1 件もないとき、見出しごと出さない(F27-AC11)。リンクは `rel="noopener nofollow ugc"` を付け、新しいタブでは開かない。長い題名は、1 行で切って `…` を付け、全文を `title` に入れる。サイト名も、長いときは切る。丸いリンクは横に並べて折り返し、幅 375px で横にはみ出さない(F27-AC20、ブラウザのテスト)。

viewer の CSP は変えない。リンクは移動先を開くだけで、動画は埋め込まない(D-55)。

## 取り込まないもの

- 引用として数えない(F27-AC16)。引用の検出は、版の HTML の受け取りの確定だけが呼ぶので、関連リンクの経路は引用の表に書かない(テストで、共有 URL を足しても `citations` が空のままであることを確かめる)。
- 画像は取らない。題名は足す 1 回だけで、見せるときも、あとからも取り直さない(F27-AC29)。

## 題名の自動取得

2026-11-23、依頼者の判断で足した(F27-AC21〜AC31)。題名の入力が空のときだけ、足す 1 回、リンク先の題名を取る。純粋な部分と境界を、ファイルで分ける。

| ファイル | 層 | 役割 |
| --- | --- | --- |
| `src/links/title-policy.ts` | 純粋 | 問い合わせてよい先か(`fetchTarget`)。リダイレクトの status と上限 |
| `src/links/title-parse.ts` | 純粋 | HTML の先頭から題名を読む(`titleOfPage`)。`og:title`、なければ `<title>`。文字の参照は `entities` で解く |
| `src/links/title-client.ts` | client | 問い合わせ(`fetchLinkTitle`)。`fetcher` を引数にして、テストは実ネットワークに出ない |
| `src/links/api.ts` | routes | 追加の入口(`addLinkWithTitle`)。取得してから、D1 に入れる |

- **問い合わせない先(SSRF 対策)**: `https:` 以外、IP アドレスのホスト(URL の解析が 10 進・16 進・8 進を点つきの 10 進に直すので 1 つの検査で足りる。IPv6 は `[` で始まる)、`localhost`、`.local`・`.internal`・`.localhost`・`.workers.dev` で終わる名前(`wrangler.jsonc` に `workers_dev` の指定がなく、`*.workers.dev` でも配られうる。サブドメインはここでは分からないので、全部を避ける)、ドットのない名前、443 以外のポート、利用者名つき、サービス自身(`PUBLIC_ORIGIN`)と配信ドメイン(`CONTENT_ORIGIN`)のホストとその下のホスト。リンクは保存し、問い合わせだけしない。Workers は非公開の IP へ出られないが、守りは自分でも持つ。
- **リダイレクト**: `redirect: 'manual'` で 3 回まで。行き先は、最初の URL と同じ検査(`fetchTarget`)に通す。4 回目の redirect は追わない。
- **時間と量**: 全体で 3 秒(`AbortSignal.timeout`。リダイレクトも本文の読み取りも含む)。`text/html` で status 200 の答えだけを読み、先頭 64 KB を読んだら `cancel()` で打ち切る。Accept は `text/html`、User-Agent は `slide-link-title/1.0`。`credentials: 'omit'`、`referrerPolicy: 'no-referrer'` で、cookie も Authorization も送らない。
- **文字コード**: Content-Type の charset、なければ先頭 1,024 バイトの `<meta charset>`・`<meta http-equiv>` で決め、`TextDecoder` で読む(Shift_JIS、EUC-JP、ISO-2022-JP を含む。知らない名前は UTF-8)。64 KB で切れた末尾は `stream` で復号するので、途中で切れた文字は U+FFFD にならず捨てられる。U+FFFD を含む題名は、読めなかったものとして題名なしにする。
- **題名の読み取り**: 元の文字列の上を 1 度だけ左から右へ手書きで走査する(`scanPage`)。大文字小文字は元の文字列の上で見る(小文字にした写しの添字はずれることがある)。引用符を認識し、引用符の中の `>` でタグを切らない。`<title` は名前が `title` のときだけで、コメント、`<script>`、`<style>` は読み飛ばす。閉じないタグは 4,096 文字で諦め、読んだ分の先から続けるので、同じ文字を二度は見ない。走査の回数を数えて、長さの定数倍に収まることをテストで確かめる。`og:title` の `content` を先に、なければ `<title>`。解いた文字の参照のあと、`fetchedTitleOf` が、空白を 1 つにまとめ、前後を削り、制御・書式・区切りの文字や見える文字のないものは NULL にし、100 文字(コードポイント)で切る。取った題名は信用せず、画面では既存の `html` テンプレートが escape する。
- **失敗は題名なし**: 取れない、答えない、HTML でない、題名がない、検査に通らない、は全て null。追加は失敗しない。
- **追加との順**: 取得は追加のリクエストの中で、D1 への挿入の前に行う(3 秒を超えない)。先に安い読み(`readAddRoom`)で、持ち主・生存・件数を見て、上限に達した・ほかの人の・削除済みのスライドでは取りに行かない(F27-AC32)。10 件の上限と持ち主の確認は、挿入の 1 文のままで、同時に足されて取得が重なっても、上限は守られる(読みと挿入の間の競合では、取得が 1 回無駄になりうる)。
- **頻度の制限**: 作者ごとに 1 分に 6 回。新しい binding は足さず、`PAGE_SHOT_RATE_LIMITER`(1 つの key に 1 分 6 回)を、`link-title:<利用者の id>` の key で使う。超えたときは取らずに題名なしで足す。binding の既定の動きは、ローカルでは確かめず、数える key と使い方をテストで確かめた。
- **MCP**: `add_related_link` の `title` を省くと同じ取得をし、答えの `titleSource` に `given`、`fetched`、`none` を返す。
- **プライバシー**: サービスの Worker が、作者の足したリンク先へ 1 回、cookie なしで問い合わせる。作者のブラウザや読者の情報は送らない。プライバシーポリシーに書く必要があるかは、依頼者が判断する。

## 消す

`src/decks/deletion-store.ts` の `deletionSteps` が、スライドを削除済みにする同じ batch で、そのリンクを消す。スライドの削除と、退会(持っているすべてのスライド)の両方に効く(F27-AC18、AC19)。削除済みのスライドには、リンクを足せない。
