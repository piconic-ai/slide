# 引用を試す

スライドへの反応を、そのスライドの下に集める機能の試作。まず、ほかのスライドからの引用を扱う。仕様は未確定で、動かして判断するために置いている。採用する場合は feature とストーリーマップに書き起こす。

## できること

- **ページ番号つきの共有 URL**: `/@handle/slug/6` で 6 ページ目から開く。viewer はデッキの URL に `#6` を付けて渡すので、fragment の番号でページを開くデッキ(peitho、Marp など)で効く。
- **引用の検出**: アップロードの finalize で、デッキの HTML(最大 200 ファイル、各 512KB まで)から共有 URL へのリンクを読み、`citations` に保存する。引用したデッキが一般公開されている間だけ数える。
- **スライド内のリンクで引用元へ移動する**: デッキは sandbox 内で動き、viewer を移動できない。読者がデッキ内の共有 URL へのリンクを押すと、デッキの iframe がその URL を要求する。サービスは iframe からの要求(`Sec-Fetch-Dest: iframe`)に、viewer へ移動を依頼するだけのページを返し、viewer は自分の origin からの依頼で、共有 URL の path である場合だけ移動する。デッキが読者を送れるのは、このサービスの共有 URL だけになる。
- **viewer の構成**: スライドを画面の上に置き、その下に題名、作者、全画面表示、共有 URL を置く。
- **引用の表示**: スライドの下に「このスライドを引用しているスライド」と「このスライドが引用しているスライド」を、埋め込みで表示する。何ページ引用していてもデッキごとに一つで、本体と同じ sandbox の iframe で動く。それぞれ公開が新しい順に 4 件までを表示し、残りは件数だけを示す。埋め込みは 1280×720 で描画して縮小する。
- **viewer から外した導線**: 「資料だけを開く」。出回る URL を共有 URL だけにするため。

純粋なロジックは `src/reactions/` の `citation.ts`・`citing.ts`、D1 は `store.ts`、R2 の読み取りは `record.ts`、画面は `pages.ts` に分けている。

## 確認したこと

- 自動テスト: リンクの解析と、引用しているデッキの並びは Vitest の単体テスト。viewer の表示、CSP、finalize 時の記録は `src/reactions/routes.test.ts` がローカル D1・R2 を通して確認する。
- ブラウザ: デッキ内のリンクで引用元へ移動すること、戻ると元のデッキに帰ること、デッキ自身が移動を依頼しても viewer が動かないことを `src/share/viewer.browser.test.ts` が Chromium・Firefox・WebKit で確認する。

## 決めていないこと

- 読者がデッキの中でページをめくっても、viewer は今のページを知らない。共有 URL を今のページに合わせるには、デッキから viewer へ伝える取り決めが要る。
- デッキ内のリンクで移動した後に戻ると、デッキは最初のページから読み込み直す。履歴には iframe の移動の分が一つ残る。
- 引用が 4 件を超えたときに、残りを見る画面。今は件数だけを示す。
- 引用されたことを作者へ通知する方法。今は viewer に出るだけ。
- 本番への反映。migration `0013_citations.sql` を含むため、[本番に反映する](deploy.md)の手順に従う。
